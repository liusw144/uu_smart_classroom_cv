# 完成标准

工程任务完成：实现与任务范围一致，关键正反例通过，根门禁与受影响模块检查通过，契约及迁移同步，中文注释符合约束；说明真实运行命令和未验证边界。

功能任务完成：在前后端与真实存储链路跑通，权限反例验证，失败、超时、重复提交和取消行为明确。仅有单元测试或静态页面不能标记完整业务完成。

算法任务完成：真实权重与规则版本、模型哈希和来源登记；固定课堂标注集逐类评估；记录未知、遮挡与小目标覆盖度，真实硬件测量吞吐。工程 mock 不能记作算法验证。

生产候选完成：生产阻塞清零；四模式按承诺范围验收；数据库恢复、节点认证、日志审计、数据保留、密钥、容量和回滚有证据；发布责任人审定。上线状态与“构建通过”分开。

证据必须是实际执行产生的材料。不能为通过 production 命令建立虚假证据文件或删掉 production_blockers。
