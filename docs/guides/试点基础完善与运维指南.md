# 试点基础完善与运维指南

本轮沿用原目录与技术栈。用户明确暂不访问实体摄像头；本轮设备验证只使用公开视频文件。本轮仍是本机试点准备，不是生产发布。

## 持续验证

`.github/workflows/verify.yml`在push、PR和手动触发时执行根门禁/单元、Vue双端构建、FastAPI、edge、MySQL/Redis Java联调及真实浏览器核心回归。远程动作固定SHA，来源与版本见harness/ci-actions.lock.json。工作流只有contents:read，不发布部署，不保存Git凭据。

CI数据库和口令是一次性测试夹具，应用账号和会话密钥每轮随机生成；不读取开发者`.env.local`。脚本拒绝覆盖已有配置。只上传JUnit和脱敏测试汇总，排除.env、数据库备份、权重及素材。

当前本地已用官方actionlint校验工作流；远程GitHub执行需要提交和推送后观察，不能把本机通过写成远程CI通过。仓库分支保护还需将本工作流设置为必需检查。真实权重/Qwen回归在本机单独执行，不在普通PR里假装加载模型。

## 节点活性与续租

最近90秒有认证领取/心跳的启用节点才接受新作业。学校管理员的“边缘节点”页可查看本校在线状态、最近心跳、等待和执行数量；教师不能查看节点清单，浏览器不接收节点令牌或哈希。

edge在推理线程运行期间，由主线程每30秒续租并提交新的到期时间到SQLite。内部心跳返回完整、身份不变的新租约；作业、输入、模型、节点与租约不允许被更换。网络错误保留本地状态，取消或失效仍由Java拒绝。结果已完成但确认丢失时，即使本地租约时钟已过期也尝试服务端幂等确认，避免误丢已接受结果。

一个Outbox由系统文件锁限定一个执行器。诊断时可用`python scripts/local_dev.py edge --once --phase infer --heartbeat-seconds 1`观察较长推理的续租；常规运行保留30秒间隔，避免频繁请求。

## 全片视频采样

仍限制MP4 32MB、30秒和最多32帧。短片固定间隔采样并包含尾帧，低帧率不重复计数同一帧；采样数量超限时均匀分布到整段视频，包含第一帧和最后可解码帧。结果版本2新增sampling_strategy、coverage_start_ms和coverage_end_ms；Java兼容既有版本1回传，旧数据库报告可继续查看。

页面显示原片时长与采样范围。输出是采样摘要视频，不是逐帧分析、原片帧率或独立人物统计。末尾时间指最后可解码帧的时间戳，可能早于容器时长一个帧周期。

先启动backend和vision、停止普通edge，执行`python scripts/verify_trial.py`，脚本用MMPose公开视频循环生成12秒片，验证32帧全片覆盖、真实推理期间自动续租、回传及节点状态。原始模型精度仍需课堂标注。

## 备份与隔离恢复

先停止backend与edge，再从项目根目录执行：

```powershell
python scripts/backup_local.py backup
python scripts/backup_local.py verify --backup-dir runtime/backups/实际生成目录
python scripts/backup_local.py restore-test --backup-dir runtime/backups/实际生成目录
```

工具要求维护窗口，使用维护标记阻止launcher启动写服务，使用与edge一致的系统锁确认执行器停止。备份包括业务库、素材、结果、边缘缓存与SQLite一致性副本；保存哈希清单，不包含模型权重或.env凭据。

恢复只新建`uu_cv_restore_随机12位十六进制`库。名称冲突即失败；不覆盖或删除现有库。SQL导入使用只拥有该新库权限的临时账号，完成或失败后回收账号。视图重新绑定恢复库，并使用INVOKER，避免恢复视图回指业务库或依赖已回收账号。

验证数据内容摘要、表/视图清单、每个素材文件及维护窗口中原业务库未变；恢复后隔离库和文件保留供检查。这里不自动将恢复库切换成正式业务库，也不自动删除隔离库。

数据库SQL可能包含账号哈希、学校资料和素材引用，必须留在Git忽略的runtime/backups；不要作为公开附件分享。凭据要另行安全保管。当前是停写维护窗口方案，未实现在线跨存储一致快照、增量恢复或生产RPO/RTO承诺。

## 摄像头与RTSP接入工具

不带参数只显示用法，不自动打开设备。文件模式已本机验证：

```powershell
# 在fastapi目录执行，仅访问现有公开视频文件：
uv run python scripts/capture_source.py --input-file ../runtime/demo/upstream-demo.mp4 --seconds 2 --max-frames 10
```

输出为runtime/capture中的短MP4和JSON，可通过教师端现有上传流程继续分析。默认最长5秒，允许1—30秒、最多300帧、32MB，子进程超时后终止。源地址与凭据不写日志。

以下命令只有获得设备使用授权后才手动运行，本轮未执行：

```powershell
uv run python scripts/capture_source.py --device 0 --allow-device --seconds 5
uv run python scripts/capture_source.py --rtsp-env CAMERA_RTSP_URL --allow-device --seconds 5
```

RTSP地址放项目根目录Git忽略的`.env.camera`，键为CAMERA_RTSP_URL；不在命令行或聊天输入密码。工具只读取CAMERA_RTSP_前缀项，拒绝HTTP源及读取其他凭据变量。实体设备、网络摄像头兼容性、掉线恢复及长期采集仍未验收；此工具不等于已交付24小时RTSP平台。

## 课堂标注准备

操作见docs/datasets/课堂标注准备.md。`scripts/classroom_dataset.py`校验路径、哈希、框坐标、类别与分组划分，拒绝同一拍摄批次跨训练/评测集；至少3个独立批次才能生成train/val/test。

未提供人工标注数据时不会生成准确率。新脚本不将通用人物框或抬手候选自动标为人工真值。
