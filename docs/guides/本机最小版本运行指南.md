## 本机数据库

使用MySQL 8.4的3306端口和Redis的6379端口。业务库为 `uu_classroom_local`，测试库为 `uu_classroom_test`；应用和测试各有独立随机密码账号，只授权对应数据库，应用不使用数据库管理账号。Redis会话使用14号库，集成测试使用15号库，不执行FLUSHDB或FLUSHALL。其他数据库不作为本项目业务库。

本机Redis为5.0.14，启动脚本明确启用兼容模式，以原子脚本保留会话剩余TTL；这不是生产Redis选型结论。

在另一台机器首次配置时，将根目录 `.env.local.example` 复制为 `.env.local`，填写该机器自己的MySQL账号、客户端和Java 21路径。然后从项目根目录运行：

```powershell
python scripts/local_dev.py init
```

初始化只创建专用库、专用账号和保存随机凭据；遇目标库内非本项目表时会停止。不要把现有业务库改名成测试库来运行验收。

## 安装、检查与启动

需要Java 21、Maven 3.9+、Node 22、Python 3.12和uv。运行脚本会为Java进程使用配置的JDK21，避免系统默认Java8。依赖分别在模块内安装：

```powershell
Set-Location D:\self\uu_smart_classroom_cv\frontend
npm ci
Set-Location ..\fastapi
uv sync --frozen
Set-Location ..
python scripts/local_dev.py build
python scripts/local_dev.py test
```

本轮测试已运行通过，无须为了打开页面再次重建。重新安装npm依赖前先停止两个Vite进程；Windows会锁定正在使用的原生依赖文件，否则npm ci可能返回EPERM。重建Java前也先停止对应服务。

在4个IDEA终端中分别运行下面一条命令，每个终端均位于项目根目录。它们以前台方式运行，按Ctrl+C停止对应进程：

```powershell
python scripts/local_dev.py backend
python scripts/local_dev.py vision
python scripts/local_dev.py teacher
python scripts/local_dev.py admin
```

业务服务启动后，首次准备开发教师账号和模型档案：

```powershell
python scripts/local_dev.py seed
```

seed不会覆盖已有管理员密码或伪造模型权重；新建教师的随机密码保存在本机环境文件。当前启动采用dev配置，已有管理员不会因重复启动而重置密码。不要将此初始化方式直接用于生产。

## 建议体验顺序

1. 教师端登录，依次新增班级、课程、课堂任务。课程负责人继承班级，任务的负责人和班级由课程决定。有引用时删除会被拒绝。
2. 管理员可维护本校用户、公告、模型与行为类别档案。管理员替教师上传课堂图片时，服务端根据已授权的课堂任务确定素材负责人。
3. 图片检测选择任务和模型档案，提交10MB以内的PNG/JPEG。当前没有真实模型，作业会保存为失败并展示“模型未加载”，不会生成识别框、专注度或行为统计。
4. 在素材管理查看图片并清理未使用素材；被头像或检测记录引用的素材不能直接删除。个人中心可保存资料、头像和验证原密码后改密；改密后需重新登录。
5. 在教务汇总报告中选任务生成本地模板，查看详情并使用“打印 / 导出PDF”，在浏览器打印目标中选择保存为PDF。报告含编号、时间、正文和来源标识，不属于AI课堂行为分析。
