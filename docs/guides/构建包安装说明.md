# 服务构建包安装说明

此文件随 GitHub 构建 ZIP 一起交付。它是已编译服务的集成验证包，需要外部依赖、单独配置和模型，不是生产发布许可或 Windows EXE。默认 CPU，不包含录像、学生资料、模型权重、私钥或真实环境配置。

## 包内容与来源

```text
backend/classroom-api.jar
frontend/teacher/          教师端静态文件
frontend/admin/            管理端静态文件
frontend/nginx.conf        需按目标环境修改的静态服务示例
python/fastapi/            wheel、requirements.txt、pyproject.toml、uv.lock
python/edge/               独立 wheel 与依赖
python/ops/                独立 wheel 与依赖
models/demo-assets.lock.json
contracts/edge-lease.schema.json
LICENSE、NOTICE、THIRD_PARTY_NOTICES.md
build-manifest.json
安装说明.md
```

安装前核对外部 ZIP 的 SHA-256、清单提交号与 Actions 运行一致。本机有未提交代码的手动包名称含 `-local`，清单 `source_dirty=true`，不能当作干净 Git 提交的产物。校验不一致时重新下载并核查，不能继续安装。

## 运行环境

- Java 21、Python 3.12、uv 0.12.18；每个 Python 服务使用独立虚拟环境。
- MySQL 8.4、Redis 7.4；新建专用数据库与最小权限账号，不使用 root 运行应用。
- 视觉视频需要 FFmpeg 可执行文件，以及适合宿主系统的系统库。Linux 本项目 CI 使用 FFmpeg、libglib2.0-0、libgl1；部署机安装包名按发行版核对。
- NGINX 或同等静态文件/反向代理服务。运行已构建前端不需要 Node.js。
- 依赖从锁定索引下载，需要网络；完全离线部署还需目标平台的完整 wheelhouse，本包未包含。

## 安装 Python 服务

以下命令在 ZIP 解压根目录执行，演示 Windows/PowerShell；Linux 将 `.venv/Scripts/python.exe` 改为 `.venv/bin/python`。在新环境安装，不覆盖正在运行的虚拟环境。

```powershell
foreach ($module in @('fastapi', 'edge', 'ops')) {
    $moduleDir = Join-Path 'python' $module
    uv venv --python 3.12 (Join-Path $moduleDir '.venv')
    if ($LASTEXITCODE -ne 0) { throw "创建 $module 环境失败" }
    $modulePython = Join-Path $moduleDir '.venv/Scripts/python.exe'
    uv pip sync --python $modulePython --require-hashes (Join-Path $moduleDir 'requirements.txt')
    if ($LASTEXITCODE -ne 0) { throw "安装 $module 锁定依赖失败" }
    $moduleWheel = Get-ChildItem -LiteralPath $moduleDir -Filter '*.whl' -File
    if (@($moduleWheel).Count -ne 1) { throw "$module 安装包数量异常" }
    uv pip install --python $modulePython --no-deps $moduleWheel.FullName
    if ($LASTEXITCODE -ne 0) { throw "安装 $module 应用失败" }
}
```

必须先安装 `requirements.txt`，再用 `--no-deps` 安装项目 wheel，避免绕过锁定版本及 FastAPI 的无 GUI OpenCV 排除规则。`pyproject.toml`、`uv.lock` 用于来源核查；这里不包含 Python 源码，不应在解压目录直接执行 `uv sync` 构建源码。

检查入口：

```powershell
& '.\python\fastapi\.venv\Scripts\python.exe' -c 'from classroom_vision.main import create_app; print("视觉入口可导入")'
& '.\python\edge\.venv\Scripts\python.exe' -m classroom_edge.worker --help
& '.\python\ops\.venv\Scripts\python.exe' -m classroom_ops.pki --help
```

入口导入不代表模型就绪。真实模型须根据同提交仓库的 `models/demo-assets.lock.json` 校验下载并配置；AI 报告需要另行部署兼容的 AI 服务。演示准备工具位于源码仓库 `scripts/setup_demo.py`，不随本包运行，也不默认下载学生素材。

## 配置与启动

本包不携带本机 `.env.local`。JAR、普通 Python 入口不会自动读取源码开发启动器的根配置；通过进程环境变量或部署系统单独注入。

只做回环地址上的基础教务验证时，Java 需要至少配置 `SPRING_PROFILES_ACTIVE=dev`、`SERVER_ADDRESS=127.0.0.1`、`DB_URL`、`DB_USER`、`DB_PASSWORD`、`REDIS_HOST`、`REDIS_PORT`、`REDIS_DATABASE`、`REDIS_PASSWORD`，并将 `CLASSROOM_ASSETS_ROOT`、`CLASSROOM_ARTIFACT_ROOT` 指向本环境独立数据目录。新测试环境首次创建管理员时配置 `BOOTSTRAP_ENABLED=true` 和随机 `BOOTSTRAP_PASSWORD`，初始化后关闭；不使用演示口令。

```powershell
java -jar '.\backend\classroom-api.jar'
```

访问 `http://127.0.0.1:8089/actuator/health/readiness`。同提交源码根 README 记录完整配置项，必须结合清单 SHA 查阅，不能照搬其他版本的配置。

视觉配置 `VISION_APP_ENV=development`、`VISION_DEVICE=cpu`、`VISION_DEVICE_ID=0`、至少32字符的随机 `VISION_SERVICE_TOKEN` 和绝对路径 `VISION_MODEL_LOCK`、`VISION_MODELS_ROOT`、`VISION_ASSET_CACHE`、`VISION_RESULT_ROOT` 后，可在单独终端启动：

```powershell
& '.\python\fastapi\.venv\Scripts\python.exe' -m uvicorn classroom_vision.main:create_app --factory --host 127.0.0.1 --port 5000
```

未配置实际模型时 `/health/ready` 返回不可用是预期。启用真实推理需另设 `VISION_ENGINE=onnx` 并实际加载模型。edge 至少配置 `EDGE_CONTROL_URL`、`EDGE_NODE_ID`、`EDGE_SERVICE_TOKEN`、`VISION_URL`、`VISION_SERVICE_TOKEN`、独立绝对路径 `EDGE_STATE_ROOT` 和指向包内 `contracts/edge-lease.schema.json` 的 `EDGE_LEASE_SCHEMA`；TLS 要求按同提交源码配置。随后执行 `python/edge/.venv/Scripts/python.exe -m classroom_edge.worker`。Java 视觉/节点令牌与对应服务必须一致；浏览器只调用 Java，不能直连视觉接口。真实分析还需注册有效模型及素材，并开启业务流水线；只启动入口不会产生检测结果。

## 前端与数据库升级

两个静态目录分别使用独立站点服务，不可合并覆盖。`frontend/nginx.conf` 是容器式默认示例：`root` 与 `backend:8089` 均需改为目标目录和实际 Java 上游；独立 Linux/Windows 主机通常不能解析容器名 `backend`。保持 `/api/` 反向代理和 SPA 回退，外部访问按部署要求配置 TLS。

Java 启动会按 JAR 内 Flyway 迁移升级数据库。**已有环境先完整备份并验证恢复，停止旧后端与写入节点，在维护窗口协调升级前后端；不得让旧版本继续写升级后的结构。** 本轮课堂历史 V11/V12 已有专用测试库验证，本机业务库并未因打包而升级。回滚不能简单运行旧 JAR，须依据同版本迁移及恢复方案操作。

本包不安装后台服务、不修改防火墙、不连摄像头、不自动迁移现有生产环境。GPU/华为昇腾需要独立运行时与对应驱动，不能在本 CPU 包中只修改设备变量就视为支持已验收。
