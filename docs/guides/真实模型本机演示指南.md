## 首次准备与再次启动

在项目根目录执行：

```powershell
python scripts/setup_demo.py
# 只核验已下载文件，不重新下载：
python scripts/setup_demo.py --verify-only
```

脚本下载已锁定素材、验证体积和哈希、安全解压、创建虚拟摄像头文件，并启用`.env.local`的`REAL_DEMO_ENABLED=true`。首次机器仍需按原本机指南配置MySQL/Redis、执行`local_dev.py init`及安装三个原模块依赖；edge另在其目录执行`uv sync --frozen`。

构建前停止正在运行的backend，Windows会锁定运行中的JAR：

```powershell
python scripts/local_dev.py build
```

分别在独立终端启动ai、vision、backend、edge及两个前端，随后执行：

```powershell

```

seed创建真实版本`yolox-tiny-rtmpose-s-v1`的本校模型档案；节点凭据由dev环境启动时注册，已存在且不匹配时拒绝自动覆盖。账号或学校停用仍由Java拒绝访问。生产模式不会接受开发节点认证启动。

## 操作演示

登录教师端，选择已有的“开源模型验证”课堂任务，进入“视觉检测”。模型选择锁定的YOLOX与RTMPose版本。

1. 上传`runtime/demo/image.jpg`：实际推理检出5个人物，每个人含17个姿态关键点。
2. 上传`runtime/demo/upstream-demo.mp4`：采样4帧，累计31人次，查看实际标注MP4。
3. 点击“生成本地AI分析”：Java把结构化统计发送给本机Qwen，保存`LOCAL_QWEN3`报告、关联作业、模型与权重哈希。原图/视频不发送给AI模型站。
4. 摄像头仅在点击“启动摄像头采样”后请求权限；每轮最多5帧，等待上一帧作业结束才提交下一帧，可手动停止。浏览器关闭或离开页面时释放设备。

自动验收使用公开视频生成的Y4M作为Chrome虚拟摄像头，跑通了真实getUserMedia、Canvas采样、Java上传、节点推理及结果展示；没有自动打开实体摄像头。实际摄像头需要用户在浏览器允许权限，HTTPS远程部署和真实设备兼容性尚未验收。

图片限制PNG/JPEG、10MB；MP4限制32MB、30秒；推理最长边1280，最多32帧，每帧最多16个人物。短片按250ms采样并包含尾帧；超出32帧预算时均匀覆盖全片，结果版本2显示实际采样范围。极端长宽比会明确拒绝。当前不是持续RTSP系统，也不支持无限视频、批量高并发或全天摄像头录像。

## 边缘与权限实现

Java MySQL保存QUEUED/RUNNING/SUCCEEDED/FAILED/CANCELLED状态、分配节点、600秒租约和最多3次发放。节点通过独立哈希令牌、X-Node-ID、X-Job-Lease访问内部接口；学校、节点、作业、owner、租约同时约束。普通Sa-Token用户不能领取节点任务。

edge领取租约后保存SQLite Outbox，下载输入并核验SHA256；FastAPI只接受UUID、哈希、版本和媒体类型，不接受任意路径/URL，也不连接业务数据库。结果JSON包含人物框、17点坐标/分数、候选规则、时间戳、模型哈希和产物哈希；Java校验明细与统计后才接受回传。回传幂等仍核验产物，不接受篡改重放。

Outbox状态为CLAIMED→CACHED→RESULT_READY→DELIVERED，失效/取消/过期为REJECTED。已缓存任务可在管理端停机时计算，结果落盘后可重启进程并重试回传。超出租约不能作为有效结果回传；控制面恢复后可重新领取新租约。在线推理开始前及推理期间自动续租；没有离线新登录、教务编辑或无限离线续租能力。

## 可行性与下一步

现有技术组合能够落实本机CPU演示，并保留统一代码、控制面与边缘推理解耦方向。FastAPI适合ONNX推理封装；Java/Sa-Token承载用户、学校与资源归属；SQLite Outbox解决短时断网持久化。当前单机实测不是混合云或生产容量验收。

YOLOX/RTMPose是通用人物与姿态模型。只有抬腕高于肩部且关键点分数满足阈值时生成HAND_UP_CANDIDATE；这不是课堂举手分类准确率。累计人次是每帧人数相加，不能解释为独立学生人数；没有跟踪、课堂行为分类、睡觉/专注度或教学质量判断。

Qwen0.6B在本机运行成本小，但实际输出出现过把“31人次”写成“31个样例”的表述偏差。固定事实面板是数值依据，AI内容明确标记需人工核对。后续应在同一接口上评测更大模型、结构化生成及事实一致性校验，不能直接把当前文字用于正式评价。

生产前仍需课堂标注集和评测、实体摄像头/RTSP验证、mTLS和证书轮换、长期离线与磁盘保留策略、限流、恢复和容量测试。混合云还需把原始素材存储/上传留在校内边缘域；本次Java与素材均在同一台本机，尚未验证云端控制面与校内存储的分离。生产门禁继续拒绝放行。
