# 生产能力补齐实施计划

依据用户持续执行授权，沿用统一控制面与校内边缘推理解耦、原项目根目录和原位实施方式。目标规模：10所学校、1000个摄像头来源、300间课堂短片/录像后分析。用户已确认不做持续实时分析，尚未采购GPU；完成窗口SLA未确认，不能把本机样例外推为300路实际容量。

设计取舍：保留Sa-Token和现有租约。节点采用原生TLS客户端证书加数据库证书绑定/吊销，继续校验节点令牌；不信任转发证书头。证书轮换允许短期重叠。边缘侧先持久预留磁盘预算，终态按保留期回收，不能删除未确认结果腾空间。控制面限制租户与节点在途作业，按节点容量分配；拒绝时不伪造排队成功。现有单进程CPU执行器保留为可测量基线，不冒充实时300路系统。
