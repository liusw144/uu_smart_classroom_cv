# 一次课堂的教务快照与生命周期

用户已同意业务评审中的分阶段完善顺序。本批交付B07教务历史保护及B06课堂时段基础；多人授课、设备绑定、录像父任务和分析配置快照另立任务，不能视为已完成。

沿用lesson_task及现有学校/负责人权限，增加持久class_id和创建时的课程、班级、年级、人数、学期、负责人显示名快照。创建时捕获；未开始且没有任何分析/报告记录时允许显式换课程并重建快照；普通改名/改时间不刷新快照。历史数据在V11按升级时现值回填，source标为LEGACY_BACKFILL，不伪造当时信息。

新课次初态PLANNED；旧数据初态LEGACY。PLANNED/LEGACY可开始为IN_PROGRESS，开始必须给出合法实际时间（LEGACY必须显式提供）；IN_PROGRESS可完成为COMPLETED，结束晚于开始且不晚于服务器当前时间；COMPLETED或LEGACY可归档为ARCHIVED。归档前不得有QUEUED/RUNNING作业。归档后只读，现有结果可查询。计划起止时间和教室名称是可选元数据，未关联摄像头。

关键资料在课堂开始、存在任何检测或报告后锁定。非PLANNED不允许直接删除；PLANNED删除仍受引用约束。既有PUT兼容可不传version；新界面传version以拒绝过期修改。生命周期操作必须传version。所有状态判断及持久化在同一事务锁定课次；创建作业/报告也锁同一课次，防止归档并发穿透。每次创建/编辑/状态转换保存学校内可见事件。

采用现有实体扩展加嵌套snapshot契约，避免立即重建全套教务表；只禁课程修改无法保护班级人数/姓名变化，且会妨碍未来课程维护。新表复制整套课堂会引入双重ID和旧接口迁移，本批不采用。

V11仅新增迁移；旧部署需按维护窗口备份升级。本批只迁移专用测试库，业务库升级另走运维流程。所有人工说明中文，不写入凭据、真实课堂、模型指标或生产通过结论。

实施补充：V11在专用库验证后保留不变，另加V12保存永久冻结标记，避免删除全部分析记录后重新编辑/删除课堂。归档保护同时覆盖旧检测/报告删除入口；报告正文保留历史初始化来源。新旧后端不得混跑写入升级后的课堂表，按维护窗口切换。

验收覆盖课程转班后历史不变、班级/负责人改名后快照不变、同/跨校访问、过期版本、非法状态/时间、已有分析锁定、归档后提交拒绝、活动作业阻止归档、事件归属及教务报告采用快照。前端支持只读快照、计划时段、教室、状态操作和事件查看。
