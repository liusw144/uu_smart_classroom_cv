# 本机最小业务版本设计

日期：2026-11-02。依据：已确定的混合云设计、原功能需求、本轮全面验证报告，以及用户要求直接使用本地数据库并实现最小可验证版本的指令。

沿用 Vue 双端、Java 21/Sa-Token 控制面和独立 FastAPI；在指定项目根目录开发。继续沿用现有结构的改动成本小；整体迁移若依会改变当前结构及契约；另建演示项目不能验证现有工程。因此本轮在已有模块上实现真实持久化业务，不迁移框架。

## 本轮交付边界

- 班级、课程、课堂任务完整增查改删；教师只访问自己负责的数据，学校管理员只访问本校数据。课程继承班级负责人，任务继承课程及班级关系；存在引用时拒绝删除。
- 本校教师/管理员账号维护、停用、当前用户资料及原密码验证改密；角色、学校和所有权由服务端判断，不允许创建平台运维身份。
- 公告发布/下架、模型和行为类别档案、请求审计查询、真实教务与检测计数。
- 受控图片素材上传/下载、检测作业和失败记录；没有真实模型时保存明确失败原因，不制造成功检测或统计。视频、摄像头、边缘离线及算法评测保持未完成状态。
- 两端提供最小业务表格和表单；仅浏览器访问Java API，视觉服务不连接业务数据库。
- 修复已确认的视觉凭据异常和错误契约；改进Harness的反例覆盖。发布门禁仍拒绝未完成的生产条件。

## 数据及可靠性

本机 MySQL 8.4 使用新建的 `uu_classroom_local`，集成测试使用专用 `uu_classroom_test`；应用和测试各有独立随机密码账号，只授权对应库。Redis仅使用会话，不清空整个实例。不得修改或删除其他数据库。

所有业务表带tenant_id，外键绑定学校；查询、修改、下载均使用服务端身份范围。数据库迁移新增V2及后续版本，不修改V1。密码只在忽略的本机环境文件保存，API、日志和Git不输出密码或令牌。

原始素材保存在本机忽略的runtime目录，用服务端生成ID定位；拒绝任意路径及远程URL。写入容量、文件类型、归属和失败状态必须校验。素材不随Git提交。

## 验收

真实MySQL/Redis启动应用后，通过HTTP验证CRUD、引用保护、禁用身份、跨学校/跨教师拒绝、个人改密、公告可见性和失败作业。浏览器通过真实API验证教师和管理端关键页面。测试与业务库隔离，测试清理只清理本次创建的测试学校及其数据。记录命令、退出码、未实现项和运行端口。

这是本机可用的最小业务版本，不是生产认证。模型、容量、mTLS、作业租约和四模式部署等阻塞不会因本轮CRUD完成而被删除。
