# 真实模型、视频、AI和离线边缘演示设计

日期：2026-11-02。依据：已批准的混合云架构与用户要求从GitHub寻找知名模型、公开视频，在本机替换不可用演示并实际运行。

## 选择

保留既有YOLOX＋RTMPose方向，用官方YOLOX-tiny COCO ONNX及RTMPose-s，CPU推理；RTMLib只承担模型预后处理。改用其他YOLO姿态一体模型会改变既有链路及许可组合，本轮不迁移。AI选择Qwen3-0.6B官方GGUF与llama.cpp便携服务，不安装系统级模型服务。本机32GB内存，无NVIDIA显卡；不承诺GPU或实时帧率。

代码和文档来源GitHub，权重来自作者仓库链接的官方发布或模型站。记录固定版本、URL、大小、SHA256、代码许可与权重/视频资料许可的区分。所有二进制、视频、缓存均放D盘runtime，不进入Git。

## 端到端流程

浏览器只访问Java并由Sa-Token认证。Java持久化作业、绑定学校和负责人；独立边缘进程主动出站领取已授权作业，下载该作业的素材，调用本机FastAPI真实推理，保存结果及SQLite Outbox，再回传Java。FastAPI不连接业务MySQL、不接受用户路径或任意URL。

开发节点使用独立随机凭据和固定节点ID；所有下载/回传须匹配服务端分配的作业、节点和租约。学校来自数据库，不信任节点自报tenant_id。回传校验输入哈希、模型版本、结果大小和产物哈希；旧租约和取消后的回传拒绝，重复相同回传幂等。生产mTLS和证据门禁仍保持阻塞。

图片输出真实人物框和17点关键点。视频按明确的采样间隔和最大帧数处理，输出标注视频及逐帧JSON，不将累计检测次数当独立学生人数。姿态规则仅展示可解释候选（如手腕高于肩部），不把通用模型分数当课堂行为准确率。

摄像头页面由用户主动点击授权采集；自动验收使用公开视频作为虚拟摄像头输入，不打开实体摄像头，不冒充实体设备验收。

AI服务仅接收已授权作业的结构化统计和模型信息，输出标注来源的辅助报告；不上传原始视频，不以模板伪装AI输出，不让模型推断学生学习能力或情绪。模型不可用时返回明确错误。

## 离线边界

边缘只承诺已领取且已下载作业的离线执行、结果持久化和重连回传。不承诺云端断网时新登录或新增教务写入。验收采用停止本项目控制面、保留边缘SQLite、重启边缘并恢复控制面，检查相同结果不丢失且不会重复完成。

## 验收

先运行真实模型和公开视频得到可查看的产物，再完成单元、实际MySQL/Redis、浏览器和离线重放测试。没有物理设备的项目明确标为虚拟输入验证。公开样例只证明链路与计算执行，不作为课堂场景精度、生产容量或许可再分发结论。
