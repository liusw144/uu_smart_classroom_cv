# 课堂标注准备

数据留在本机Git忽略的runtime/datasets，不把学生图片或身份信息提交到仓库。先取得项目所需的素材使用授权，并在内部系统保存授权记录；清单仅记录引用，不保存姓名或联系方式。

建议先约定行为定义、可见性/遮挡规则和不确定样本的处理，再由人工标注和复核。学校、机位、拍摄时段与课堂批次用匿名代码；同一录制切出的片段必须使用相同session_id，不能随机逐帧分到不同集合。

在项目根目录：

```powershell
python scripts/classroom_dataset.py template --output runtime/datasets/new-template.json
python scripts/classroom_dataset.py validate --manifest runtime/datasets/已填写清单.json
python scripts/classroom_dataset.py split --manifest runtime/datasets/已填写清单.json --output runtime/datasets/已分组清单.json --seed trial-v1
```

输出文件必须是新文件，不覆盖已有人工清单。模板samples为空，必须人工填写后才能通过校验。单个样本格式示意如下；方括号内容需要替换，不是已经存在的标注数据：

```json
{
  "sample_id": "anonymous_sample_001",
  "school_id": "school_a",
  "session_id": "recording_a",
  "media_path": "images/sample_001.jpg",
  "sha256": "填写该文件的64位SHA256",
  "width": 1280,
  "height": 720,
  "annotation_status": "human-reviewed",
  "annotator_id": "reviewer_a",
  "authorization_ref": "内部授权记录的匿名编号",
  "split": "train",
  "frames": [{"timestamp_ms": 0, "boxes": [{"bbox": [10, 20, 100, 200], "category": "hand_up"}]}]
}
```

类别必须在顶层categories中事先定义；bbox为左上与右下坐标，不能超出图像尺寸。负样本需明确填写空boxes。图片使用timestamp_ms=0，视频按实际采样时间标注。清单与图片的哈希绑定，修改图片后必须重新审核。

分组划分使用固定seed和学校/session组合，至少3个独立录制批次；重复素材哈希拒绝导入。实际试点还应保留不同学校或机位的独立外部测试集，检查遮挡、光线、年龄段和镜头距离等条件。

工具当前验证清单结构、文件完整性、框范围与分组，不验证图片可解码、人工标注语义、授权有效性或算法精度。自动标注、人工框、模型预测必须区分来源；没有真实人工测试集与实际预测结果时，accuracy字段保持null。
