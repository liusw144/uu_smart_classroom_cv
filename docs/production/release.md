# 生产发布约束

当前禁止生产发布：harness/manifest.json 中存在明确阻塞。工程配置、构建、单元测试或页面可打开均不能替代产品验收。

发布前完成：完整业务与异常验收、真实模型/逐类评测、学校隔离、节点证书、任务恢复、媒体保留、备份恢复、硬件容量、监控告警、数据库迁移与回滚。容器镜像必须扫描并按 digest 锁定，生成依赖与模型清单，禁止直接把开发 Compose 暴露公网。

维护 harness/release-evidence.json，按 model、tenant_isolation、recovery、capacity、deployment、approval 六类记录相对证据路径和 SHA256。证据内还需绑定 Git 版本、配置、镜像、模型版本和执行环境。根 production 门禁检查材料存在与哈希；材料真实性、版本一致性和发布授权由评审责任人确认。

生产配置从密钥系统或受控文件挂载注入；不复用开发账户、口令与固定服务令牌。停止开发初始化，禁止视觉服务使用开发身份。数据库仅执行已评审新增迁移；破坏性变更必须单独批准。
