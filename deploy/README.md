# 部署模式与当前支持状态

compose.yaml 是开发基础设施和本地应用编排，所有暴露端口绑定 127.0.0.1；凭据来自本地 .env，不提供默认密码。配置解析成功不能当作镜像构建或容器联调成功。容器镜像标签仅供开发，正式发布须固定经验证 digest。

单机：可规划同机运行 Java、两前端、视觉服务、MySQL 和 Redis；当前可启动工程入口，真实检测未交付。

校内私有：完整控制面留在学校，校内网络内完成业务；需要本地存储、GPU/CPU 适配、备份和恢复验收。没有验证记录前不称为已支持生产部署。

纯云：部署同一控制面与授权的云执行节点；素材上云遵守学校配置策略，需要云对象存储、TLS、节点身份与容量验收。

混合云：云端管理＋校内边缘推理；节点主动出站，原视频默认留校。当前 Agent、mTLS、任务租约与断网恢复尚未实现。断公网期间不承诺新登录/教务写入；完整离线业务应使用校内控制面。

不会通过四份只有名称不同的 YAML 假装支持四种生产环境。后续按 tasks/backlog.json 的 M3-DEPLOY 交付各模式实际安装、升级、恢复和验收脚本。
